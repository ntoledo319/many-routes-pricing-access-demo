Keyboard checks you can run here

  • Tab to the switch — the focus ring is visible (never outline:none without a replacement).
  • Space or Enter flips monthly/yearly and the announcement log records the text supplied to the polite live region.
  • Choose 420px width — the table becomes stacked cards, highlighted plan first, no horizontal scroll.
  • Return to 960px, then Tab past the plan links to the comparison region; use arrow keys when the table overflows.
  • Choose Broken JSON — the component names the exact problem instead of rendering nothing.
